# NOCTURNE

A modern music player built with Next.js.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000/todo-next-player/](http://localhost:3000/todo-next-player/) in your browser.

## Deployment

Pushing to `main` builds and deploys the static site to [GitHub Pages](https://syntaxfox1.github.io/todo-next-player/).
